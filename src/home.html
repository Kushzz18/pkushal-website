// 02, frameworks

Named systems, not vibes.

Repeatable methodologies I run on every engagement, each one built from hundreds of real diagnoses.

FW-01

The Render-Gap Protocol

Reconcile the pre-render HTML payload against the hydrated DOM to expose exactly what crawlers and LLM agents resolve, then close the delta.

FW-02

The Graduation Engine

Classify why an indexed site stays suppressed, impressions without conversions, into discrete failure modes, and compute a data-derived exit path from Search Console.

FW-03

Entity-First Architecture

Build a machine-legible entity ontology and gate every URL through “does this query deserve a page?”, so topical authority compounds instead of diluting.

FW-04

Evidence-Bound Forensics

Interrogate first-party data, Search Console and response headers, before asserting cause. Every finding ships as Issue → Evidence → Solution → Execution.

FW-05

The Machine-Readable Layer

Structured data, semantic HTML, and AI-crawler access engineered so a site is legible to classic search and generative retrieval alike.
