# pkushal.com.np

Personal site of **Kushal Pathak — Technical SEO Strategist** (Kathmandu, Nepal).
Hand-built, statically rendered, with a live technical-SEO lab (robots.txt matcher, entity-grade schema generator, SERP
pixel-width preview, render-gap demo, hreflang, Open Graph, index-coverage tree, tiered quiz).

Live: https://pkushal.com.np

## Structure

```
src/
  home.html          # the editable page (single source of truth for content)
  assets/kushal.webp # source photo
build.py             # wraps src/home.html into site/index.html + machine files
site/                # deployable output (what gets uploaded to the server)
  index.html         # generated by build.py
  robots.txt         # HAND-MAINTAINED (ASCII art) — build.py does NOT touch it
  llms.txt sitemap.xml favicon.svg 404.html .htaccess   # generated by build.py
  <indexnow-key>.txt # IndexNow key file (public)
  assets/kushal.webp
deploy.sh            # build + upload to the server over SSH
```

## Edit → build → deploy

1. Edit **`src/home.html`** (content) and/or **`site/robots.txt`** (the fun robots file).
2. Build: `python build.py`  → regenerates `site/`.
3. Deploy: `DEPLOY_KEY="/path/to/SSHKushalWebsite_nopass" ./deploy.sh`
